# Bản export MySQL của 7 service

Bản mới nhất được thử khôi phục là `clinic-7db-complete-2026-10-23.sql.gz` trong thư mục này (SHA-256 của file nén: `622D5E2BF7C7B5743EB39D8EFEA7F438E6E4CCD12EF4C596C00F020D2BBB0616`). File được gửi riêng và Git bỏ qua vì chứa dữ liệu cá nhân. Đã import thử trực tiếp từ gzip trên MySQL Docker cách ly: 30 bảng khôi phục đúng ảnh chụp; bản SQL không nén tương ứng có SHA-256 `1FCD0706AACBE777BE996019789037E2E253ABC70619CF4C7AAF4F4A3D4375A5`. Đối chiếu nhanh: 82 tài khoản, 14 bệnh nhân, 66 nhân viên, 1.976 ca trực, 54 lịch hẹn, 49 hóa đơn, 20 lượt khám và 13 chỉ định xét nghiệm. Xem [README gốc](../../README.md) để import vào Docker và chạy hệ thống.

Chỉ import trên volume MySQL mới hoặc volume chắc chắn không có dữ liệu cần giữ. Import lại có thể ghi đè bảng. Sau khi import, dùng [`verify.sql`](verify.sql) để in số lượng bản ghi, không in CCCD hay hồ sơ. Bản export là ảnh chụp tĩnh; Git không đồng bộ dữ liệu giữa các máy. Không dùng bộ dữ liệu này trong production.
